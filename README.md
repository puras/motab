# MoTab

Chrome 新标签页自定义扩展。打开新标签页时展示：背景图、实时时钟、按时段变化的欢迎信息。

## 加载扩展

1. 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本目录（motab/）

## 更换背景

替换 `assets/wallpaper.jpg` 后，回到扩展页面点击 **重新加载**。

## 个性化问候名字

编辑 `app.js` 顶部：

```js
const NAME = "你的名字";
```

显示效果：`早上好，你的名字`。设为 `""` 则只显示时段问候。

## 开发预览（不上扩展）

```bash
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/newtab.html
```
