# MoTab

Chrome 新标签页自定义扩展(MV3)。打开新标签页时展示背景图、实时时钟、当前日期,以及按时段变化的中文欢迎信息。

纯 HTML/CSS/JS 实现,无构建工具、无第三方依赖。

## 功能特性

- **全屏背景**:加载 `assets/wallpaper.jpg`,叠加半透明暗色蒙版保证文字可读
- **实时时钟**:`HH:MM:SS` 大号细体数字,每秒刷新
- **日期显示**:中文格式,如「2026年8月26日 星期二」
- **时段问候**:按当前时间自动切换问候语,支持个性化名字

## 问候时段

| 时间 | 问候语 |
|---|---|
| 05:00 – 10:59 | 早上好 |
| 11:00 – 12:59 | 中午好 |
| 13:00 – 17:59 | 下午好 |
| 18:00 – 22:59 | 晚上好 |
| 23:00 – 04:59 | 夜深了 |

名字非空时显示为「{问候},{NAME}」。

## 加载扩展

1. 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本目录(motab/)

修改代码后回到扩展页面点击 **重新加载**,再开新标签页查看效果。

## 更换背景

替换 `assets/wallpaper.jpg` 后,重新加载扩展即可。建议使用分辨率较高的横版图片,任何文件名保持不变。

## 个性化问候名字

编辑 `app.js` 顶部:

```js
const NAME = "你的名字";
```

显示效果:`早上好,你的名字`。设为 `""` 则只显示时段问候。

## 开发预览(不上扩展)

```bash
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/newtab.html 查看效果。

## 测试

`greetingFor(hour)` 的分档边界有独立测试页,直接在浏览器打开:

```
tests/greeting.test.html
```

页面会列出 11 个边界用例(5、11、13、18、23 等整点)的 PASS/FAIL 结果。

## 项目结构

```
motab/
├── manifest.json              # Chrome MV3 扩展清单(覆盖新标签页)
├── newtab.html                # 页面结构:时钟 / 日期 / 问候语三行居中
├── style.css                  # 样式:全屏壁纸 + 蒙版 + 自适应字号(clamp)
├── app.js                     # 运行时逻辑:每秒刷新、问候分档
├── assets/
│   └── wallpaper.jpg          # 背景图(占位图,可整体替换)
├── tests/
│   └── greeting.test.html     # greetingFor 分档边界测试页
└── docs/superpowers/          # 设计文档与实施计划
```
