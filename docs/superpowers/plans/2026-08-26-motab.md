# MoTab 新标签页扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个 Chrome 扩展（Manifest V3），用 `chrome_url_overrides.new_tab` 替换新标签页，展示自定义背景图、实时时钟和按时段变化的欢迎信息。

**Architecture:** 纯前端静态页面，零权限，无后台脚本。问候逻辑抽出为纯函数便于手测；UI 用原生 HTML/CSS/JS，不引入框架。验收靠 `python3 -m http.server` 起本地静态服务 + 浏览器开 `http://localhost:8000/newtab.html` 检查页面表现，扩展加载通过 Chrome 开发者模式。

**Tech Stack:** Chrome Extension Manifest V3, HTML5, CSS3, 原生 JavaScript (ES2017+)

## Task 6: 写 app.js（运行时逻辑）

**Files:**
- Create: `/Users/puras/workspace/proj/106hz/motab/app.js`

- [ ] **Step 1: 写入 app.js**

完整内容：

```javascript
const NAME = "";

function greetingFor(hour) {
  if (hour >= 5 && hour < 11) return "早上好";
  if (hour >= 11 && hour < 13) return "中午好";
  if (hour >= 13 && hour < 18) return "下午好";
  if (hour >= 18 && hour < 23) return "晚上好";
  return "夜深了";
}

function pad2(n) { return n.toString().padStart(2, "0"); }

function formatTime(d) {
  return `${pad2(d.getHours())}:${pad2(d.getMinutes())}:${pad2(d.getSeconds())}`;
}

function formatDate(d) {
  return d.toLocaleDateString("zh-CN", {
    year: "numeric", month: "long", day: "numeric", weekday: "long"
  });
}

function composeGreeting(hour) {
  const g = greetingFor(hour);
  return NAME ? `${g}，${NAME}` : g;
}

function render() {
  const now = new Date();
  document.getElementById("time").textContent = formatTime(now);
  document.getElementById("date").textContent = formatDate(now);
  document.getElementById("greeting").textContent = composeGreeting(now.getHours());
}

render();
setInterval(render, 1000);
```
